**torch** is PyTorch's core library for tensor operations, neural networks, and autograd (automatic differentiation). [blog.csdn](https://blog.csdn.net/xiaotiig/article/details/132847320)

**torchvision** provides datasets (MNIST, CIFAR), pre-trained models (ResNet, AlexNet), and image transforms for computer vision tasks. [docs.pytorch](https://docs.pytorch.org/vision/)

**torchaudio** handles audio I/O, datasets (LibriSpeech), and transforms (MFCC, spectrograms) for speech and audio ML. [docs.pytorch](https://docs.pytorch.org/audio/main/index.html)

## Key Components
| Library     | Domain       | Main Features                  |
|-------------|--------------|--------------------------------|
| torch       | Core         | Tensors, autograd, nn.Module  |
| torchvision | Vision       | Datasets, models, transforms   |
| torchaudio  | Audio        | Audio I/O, transforms, datasets|  [blog.csdn](https://blog.csdn.net/xiaotiig/article/details/132847320)

These must match PyTorch versions exactly due to C++ ABI linking. [youtube](https://www.youtube.com/watch?v=PT8CmTewyks)
