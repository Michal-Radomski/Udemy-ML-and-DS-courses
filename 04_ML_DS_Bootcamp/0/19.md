MobileNet is a family of efficient convolutional neural network (CNN) architectures designed by Google for mobile and
embedded devices, prioritizing low latency, small size, and minimal power use.
[viso](https://viso.ai/deep-learning/mobilenet-efficient-deep-learning-for-mobile-vision/)

## Core Concept

It excels in tasks like image classification, object detection, and semantic segmentation on resource-limited hardware, such
as smartphones or IoT devices, by drastically reducing parameters and computations compared to traditional CNNs.
[en.wikipedia](https://en.wikipedia.org/wiki/MobileNet)

## Key Innovation

The primary building block is **depthwise separable convolution**, which splits standard convolution into two steps: a
depthwise convolution (applying a single filter per input channel) followed by a pointwise convolution (1x1 convolution to
mix channels). This reduces computations by 8-9x while preserving much of the accuracy.
[emergentmind](https://www.emergentmind.com/topics/mobilenet-architecture)

## How It Works

- **Input processing**: Starts with a standard convolution on the input image (e.g., 224x224 RGB) for initial feature
  extraction. [geeksforgeeks](https://www.geeksforgeeks.org/computer-vision/what-is-mobilenet-v2/)
- **Main body**: Repeats depthwise separable blocks, often with strides for downsampling; later versions (V2+) add inverted
  residuals (expand then project channels) and linear bottlenecks to minimize information loss.
  [viso](https://viso.ai/deep-learning/mobilenet-efficient-deep-learning-for-mobile-vision/)
- **Output**: Ends with global average pooling, a fully connected layer, and softmax for classification; total layers around
  28 in the original. [wikidocs](https://wikidocs.net/165429)

## Versions Overview

| Version | Key Advances                           | Use Cases                                                                                                      |
| ------- | -------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| V1      | Depthwise separable convolutions       | Basic mobile vision [viso](https://viso.ai/deep-learning/mobilenet-efficient-deep-learning-for-mobile-vision/) |
| V2      | Inverted residuals, linear bottlenecks | Higher accuracy/speed [geeksforgeeks](https://www.geeksforgeeks.org/computer-vision/what-is-mobilenet-v2/)     |
| V3      | NAS optimization, h-swish activation   | Edge-optimized [emergentmind](https://www.emergentmind.com/topics/mobilenet-architecture)                      |
| V4      | Universal block search, attention      | Latest Pareto efficiency [emergentmind](https://www.emergentmind.com/topics/mobilenet-architecture)            |

This design enables real-time inference, like running object detection on phones via TensorFlow Lite.
