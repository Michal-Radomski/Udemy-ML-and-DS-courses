# What is ReLU

ReLU, or Rectified Linear Unit, is a widely used activation function in neural networks defined as $f(x) = \max(0, x)$,
outputting the input directly if positive and zero otherwise.[^1][^3]

## How It Works

It introduces nonlinearity while keeping computations simple: positive inputs pass through unchanged, while negative ones are
blocked, creating sparse activations where only some neurons fire. The derivative is straightforward—1 for $x > 0$ and 0 for
$x \leq 0$—enabling efficient backpropagation.[^2][^3]

## Key Benefits

ReLU accelerates training by avoiding vanishing gradients common in sigmoid/tanh, as its gradient doesn't saturate for
positive values. It promotes sparsity, reducing overfitting and speeding up convergence in deep networks like
CNNs.[^2][^3][^7]

## Drawbacks

The "dying ReLU" problem occurs when neurons output zero indefinitely (gradients stay zero), stalling learning; variants like
Leaky ReLU address this.[^1][^3]

## Common Use

Applied in hidden layers of most modern deep learning models, such as image classification or NLP tasks, often with
frameworks like PyTorch or TensorFlow.[^4][^5] <span style="display:none">[^10][^6][^8][^9]</span>
