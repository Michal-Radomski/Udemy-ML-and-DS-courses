# what is logistic regression

Logistic regression is a supervised machine learning algorithm used for binary classification tasks. It predicts the
probability of a categorical outcome, such as yes/no or 0/1, based on one or more predictor variables.[^1][^2]

## Key Concept

It models the relationship between independent variables and the log-odds of the outcome using a logistic (sigmoid) function,
which outputs values between 0 and 1. Unlike linear regression, which predicts continuous values, logistic regression fits an
S-shaped curve to classify data points.[^2][^1]

## Mathematical Basis

The model uses the equation $p = \frac{1}{1 + e^{-(\beta_0 + \beta_1 x_1 + \dots + \beta_n x_n)}}$, where $p$ is the
probability, $\beta$ are coefficients, and $x$ are features. A threshold like 0.5 determines the class: above it means "1,"
below means "0."[^3][^2]

## Applications

Common uses include predicting customer churn, disease diagnosis, or spam detection. For example, it might assess loan
approval based on income and credit score.[^4][^1] <span style="display:none">[^10][^5][^6][^7][^8][^9]</span>
