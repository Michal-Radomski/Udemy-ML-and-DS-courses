# What is Perceptron

The perceptron is the simplest form of an artificial neural network, introduced by Frank Rosenblatt in 1957 as a binary
linear classifier that mimics a biological neuron.[^3][^4]

## Core Mechanism

It takes multiple input features ($x_1, x_2, \dots, x_n$), multiplies each by a learned weight ($w_i$), adds a bias term
($b$), and applies a step activation function: if $\mathbf{w} \cdot \mathbf{x} + b \geq 0$, output 1; else 0. Weights update
iteratively via the perceptron learning rule when predictions err: $w_i \leftarrow w_i + \eta (y - \hat{y}) x_i$, where
$\eta$ is the learning rate.[^1][^3]

This diagram shows a perceptron's structure: inputs flow through weighted connections to a summation, then an activation
threshold produces the binary output.

## Limitations and Legacy

It solves linearly separable problems like basic AND/OR logic but fails on non-linear ones (e.g., XOR), sparking the AI
winter after Minsky's 1969 critique. Modern multi-layer perceptrons (MLPs) extend it into deep learning foundations.[^2][^5]
