# What is activation function and loss funtion

Activation functions and loss functions are essential components in neural networks, determining how neurons process data and
how models learn from errors.

## Activation Functions

These introduce non-linearity into the network, deciding whether a neuron "fires" based on its input sum. Common types
include sigmoid ($\sigma(x) = \frac{1}{1 + e^{-x}}$, outputs 0-1 for binary tasks), ReLU ($f(x) = \max(0, x)$, efficient for
hidden layers), and tanh (outputs -1 to 1, zero-centered).[^1][^2]

## Loss Functions

These quantify prediction errors to guide optimization via backpropagation. Mean Squared Error (MSE,
$\frac{1}{n} \sum (y_i - \hat{y_i})^2$) suits regression; Cross-Entropy Loss ($- \sum y_i \log(\hat{y_i})$) fits
classification by penalizing confident wrong predictions.[^1] <span style="display:none">[^3][^4][^5][^6][^7][^8][^9]</span>
