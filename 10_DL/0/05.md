# what is gradient descent in machine learning

Gradient descent is a fundamental optimization algorithm in machine learning used to minimize a model's loss function by
iteratively adjusting parameters. It works by computing the gradient (partial derivatives) of the loss with respect to each
parameter and updating them in the direction that reduces the loss most steeply.[^1][^4]

## Core Concept

The algorithm mimics descending a hill: at each step, it moves opposite the gradient's direction, scaled by a learning rate
$\alpha$, via the update rule $\theta_{new} = \theta_{old} - \alpha \nabla J(\theta)$, where $J$ is the loss function and
$\theta$ are parameters like weights. This process repeats until convergence, when changes in loss become negligible.[^2][^5]

## Key Variants

- **Batch Gradient Descent**: Computes gradient over the entire dataset—accurate but slow for large data.[^3]
- **Stochastic Gradient Descent (SGD)**: Updates per single example—faster, noisier convergence.[^3]
- **Mini-batch Gradient Descent**: Balances speed and stability using small batches, common in practice.[^3]

## Applications

Gradient descent trains models like linear regression, logistic regression, and neural networks by finding optimal weights
that minimize prediction errors. The learning rate must be tuned: too high causes divergence, too low slows
training.[^1][^3][^6] <span style="display:none">[^10][^7][^8][^9]</span>
