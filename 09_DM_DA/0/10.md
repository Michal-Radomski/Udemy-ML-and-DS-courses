`from sklearn.manifold import TSNE` imports the t-Distributed Stochastic Neighbor Embedding (t-SNE) class from scikit-learn's
manifold learning module.

## Purpose

t-SNE is a nonlinear dimensionality reduction technique for visualizing high-dimensional data in 2D or 3D. Unlike PCA, it
excels at preserving local neighborhoods and cluster structures, making it ideal for exploratory data analysis and spotting
patterns. [simulationbased](https://simulationbased.com/2021/01/05/introduction-to-t-sne-in-python-with-scikit-learn/)

## Basic Usage

Set `n_components=2` for 2D plots and tune `perplexity` (e.g., 30–50) for neighborhood size:

```python
from sklearn.manifold import TSNE
import numpy as np

# Sample high-dimensional data
X = np.random.rand(100, 50)  # 100 samples, 50 features

tsne = TSNE(n_components=2, perplexity=30, random_state=42)
X_embedded = tsne.fit_transform(X)  # Fits and transforms data
```

Preprocess with PCA for large datasets (>5k points) to speed up computation.
[scikit-learn](https://scikit-learn.org/stable/modules/generated/sklearn.manifold.TSNE.html)

## Key Parameters

| Parameter       | Description                                                                                                                  |
| --------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `n_components`  | Output dimensions (2 or 3) [scikit-learn](https://scikit-learn.org/stable/modules/generated/sklearn.manifold.TSNE.html)      |
| `perplexity`    | Balances local/global structure (5–50)                                                                                       |
| `learning_rate` | Optimization step size (10–1000) [github](https://github.com/scikit-learn/scikit-learn/blob/main/sklearn/manifold/_t_sne.py) |
| `n_iter`        | Max iterations (default 1000)                                                                                                |
