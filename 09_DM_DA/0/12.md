Association rule learning is a popular unsupervised machine learning technique for discovering interesting relationships
between variables in large datasets, often expressed as "if-then" rules like {bread, butter} → {milk}. It originated from
market basket analysis to identify frequently co-occurring items in transactions.
[deepai](https://deepai.org/machine-learning-glossary-and-terms/association-learning)

## Core Idea

The method scans transactional data to find patterns where certain itemsets (antecedents) imply others (consequents), without
needing labeled outcomes. Rules are evaluated by metrics: support (how often the full itemset appears), confidence
(likelihood of consequent given antecedent), and lift (how much better the rule predicts than chance).
[devacomputerscience](https://devacomputerscience.in/ml_doc/Association%20Rule.pdf)

## Key Algorithms

- **Apriori**: Builds frequent itemsets iteratively by starting with single items and extending those above a support
  threshold; prunes candidates to reduce computation. [en.wikipedia](https://en.wikipedia.org/wiki/Association_rule_learning)
- **FP-Growth**: Uses a compact tree structure (FP-tree) to mine frequent patterns without generating many candidates, making
  it faster for dense datasets. [en.wikipedia](https://en.wikipedia.org/wiki/Association_rule_learning) This Venn diagram
  shows transactions containing itemsets X and Y, with overlap representing joint occurrences central to rule strength
  calculations. [cs.ubc](https://www.cs.ubc.ca/~schmidtm/Courses/340-F15/L11.pdf)

## Applications

Widely used in retail for recommendations (e.g., "customers buying diapers often buy beer"), web usage mining, and
bioinformatics for gene associations. Limitations include handling large datasets and avoiding trivial rules via minimum
thresholds. [deepai](https://deepai.org/machine-learning-glossary-and-terms/association-learning)
