`from sklearn.decomposition import PCA` imports the Principal Component Analysis class from scikit-learn's decomposition
module.

## Purpose

PCA is a dimensionality reduction technique that transforms high-dimensional data into lower dimensions by finding principal
components—orthogonal directions capturing maximum variance. It helps visualize data, reduce computation, and combat
overfitting. [sklearn](https://sklearn.org/stable/modules/generated/sklearn.decomposition.PCA.html)

## Basic Usage

Initialize with `n_components` (number of dimensions to keep, e.g., 2 for 2D plot) or a variance ratio like 0.95:

```python
from sklearn.decomposition import PCA
import numpy as np

# Sample data
X = np.array([[-1, -1], [-2, -1], [-3, -2], [1, 1], [2, 1], [3, 2]])

pca = PCA(n_components=2)
pca.fit(X)  # Learn components
X_transformed = pca.transform(X)  # Reduce dimensions

print(pca.explained_variance_ratio_)  # [0.9924 0.0075]
```

Standardize data first with `StandardScaler` for best results, as PCA is variance-sensitive.
[builtin](https://builtin.com/machine-learning/pca-in-python)

## Key Methods

| Method                      | Description                                                                                                                    |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| `fit(X)`                    | Fits model to data, computes components [sklearn](https://sklearn.org/stable/modules/generated/sklearn.decomposition.PCA.html) |
| `transform(X)`              | Projects data to principal components                                                                                          |
| `fit_transform(X)`          | Fits and transforms in one step [stackabuse](https://stackabuse.com/implementing-pca-in-python-with-scikit-learn/)             |
| `explained_variance_ratio_` | Fraction of variance per component [sklearn](https://sklearn.org/stable/modules/generated/sklearn.decomposition.PCA.html)      |
