In CHAID (Chi-square Automatic Interaction Detection) analysis, typically implemented in statistical software like Stata or
SPSS, "IV names" refers to the names of the **independent variables** (also called predictor variables) used to build the
decision tree model.

## Context in Software

CHAID splits data based on chi-square tests between a dependent variable and multiple IVs. In code like Stata's `chaid.ado`
implementation, "IV names" appear as lists such as `varsvec`, `namesvec`, or `selectnames`, which store and process the
labels or identifiers of input predictors (e.g., `ordered` or `unordered` variables) for splitting decisions. These track
variable names during tree construction, permutation importance calculations, and node labeling.
[fmwww.bc](http://fmwww.bc.edu/repec/bocode/c/chaid.ado)

## Usage Example

For a model predicting customer churn:

- DV: `churn` (dependent variable)
- IV names: `age`, `income`, `region` (these form splits based on significance).
  [vertica](https://www.vertica.com/python/old/documentation_last/vdataframe/main-methods/chaid/)

This convention helps in displaying tree structures, variable importance, and node descriptions without ambiguity.
