# What is Gaussian Mixture Model

A Gaussian Mixture Model (GMM) is a probabilistic model that represents data as a mixture of multiple Gaussian (normal)
distributions. It assumes each data point is generated from one of several underlying Gaussians, each defined by its own
mean, covariance, and mixing weight.

## Key Components

GMMs consist of _K_ Gaussian components, where each has:

- A mean vector $\mu_k$ (center of the distribution).
- A covariance matrix $\Sigma_k$ (shape and spread).
- A mixing coefficient $\pi_k$ (prior probability of belonging to component _k_, with $\sum \pi_k = 1$).

The probability density function for a data point $x$ is:

$$
p(x) = \sum_{k=1}^K \pi_k \mathcal{N}(x \mid \mu_k, \Sigma_k)
$$

where $\mathcal{N}$ is the Gaussian density.[^1][^2]

## How It Works

GMMs use the Expectation-Maximization (EM) algorithm to estimate parameters. In the E-step, it computes the probability
(responsibility) of each point belonging to each component; in the M-step, it updates means, covariances, and weights to
maximize likelihood. This enables soft clustering, unlike hard assignments in k-means.[^2][^5][^1]

## Applications

GMMs excel in density estimation, clustering complex shapes, and anomaly detection, such as modeling multimodal data like
human heights by gender.[^8][^2] <span style="display:none">[^10][^3][^4][^6][^7][^9]</span>
