Dimension reduction, also known as dimensionality reduction, is a machine learning technique that transforms high-dimensional
data into a lower-dimensional space while preserving most of its important properties. It addresses challenges like the curse
of dimensionality, where high feature counts lead to sparse data, increased computation, and overfitting.

## Key Benefits

- Reduces computational costs and storage needs by eliminating redundant or irrelevant features.
- Improves model performance by mitigating overfitting and noise.
- Enables better visualization of complex datasets, such as plotting in 2D or 3D.
  [zilliz](https://zilliz.com/glossary/dimensionality-reduction)

## Main Techniques

Two broad categories exist:

| Category           | Description                            | Examples                                                                                                                    |
| ------------------ | -------------------------------------- | --------------------------------------------------------------------------------------------------------------------------- |
| Feature Selection  | Selects a subset of original features  | Forward selection, backward elimination [techtarget](https://www.techtarget.com/whatis/definition/dimensionality-reduction) |
| Feature Extraction | Creates new features from combinations | PCA, t-SNE, UMAP, LDA [zilliz](https://zilliz.com/glossary/dimensionality-reduction)                                        |

Principal Component Analysis (PCA) finds orthogonal components maximizing variance, while t-SNE excels at preserving local
structures for visualization. [techtarget](https://www.techtarget.com/whatis/definition/dimensionality-reduction)
