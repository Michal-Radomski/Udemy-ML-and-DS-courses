Manifold learning is a technique for nonlinear dimensionality reduction that uncovers low-dimensional structures embedded in
high-dimensional data. It assumes real-world data often lies on a lower-dimensional "manifold" within a higher-dimensional
space, enabling better visualization and analysis. [haifengl.github](https://haifengl.github.io/manifold.html)

## Core Concept

High-dimensional data, like images or sensor readings, frequently has intrinsic low dimensionality due to underlying
patterns. Manifold learning algorithms "unfold" this manifold to project data into fewer dimensions while preserving local or
global relationships, generalizing methods like PCA for nonlinear cases.
[scikit-learn](https://scikit-learn.org/0.20/modules/manifold.html)

## Key Algorithms

- **Isomap**: Estimates geodesic distances on the manifold using shortest paths in a neighborhood graph, then applies
  multidimensional scaling. [rworks](https://rworks.dev/posts/manifold-learning/)
- **LLE (Locally Linear Embedding)**: Reconstructs each point as a linear combination of neighbors, preserving local geometry
  in low dimensions. [rworks](https://rworks.dev/posts/manifold-learning/)
- **t-SNE**: Focuses on local similarities via probability distributions, popular for visualization (e.g., MNIST digits) but
  not for new data projection. [haifengl.github](https://haifengl.github.io/manifold.html)
- **UMAP**: Balances local/global structure faster than t-SNE, widely used in single-cell RNA sequencing.
  [sites.gatech](https://sites.gatech.edu/omscs7641/2024/03/10/no-straight-lines-here-the-wacky-world-of-non-linear-manifold-learning/)

## Applications

Common in visualizing clusters (e.g., handwritten digits on an "S-curve") and preprocessing for machine learning tasks like
denoising or classification. Trade-offs include sensitivity to parameters like perplexity or neighborhood size.
[annualreviews](https://www.annualreviews.org/content/journals/10.1146/annurev-statistics-040522-115238)
