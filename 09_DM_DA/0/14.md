**LIME**, or Local Interpretable Model-agnostic Explanations, is a technique in machine learning used to explain individual
predictions of any "black box" model, like random forests or neural networks. It approximates the model's behavior locally
around a specific instance by perturbing the input data, weighting samples by proximity, and fitting a simple interpretable
model (usually linear regression) to those perturbations. This reveals which features most influenced the prediction for that
instance, making complex models more transparent without needing access to their internals.
[mbrenndoerfer](https://mbrenndoerfer.com/writing/lime-local-interpretable-model-agnostic-explanations)

## Installing LIME in Miniconda on Ubuntu

LIME is available as a Python package (`lime`), so activate your Miniconda environment and install it via conda or pip.
First, update conda: `conda update conda`. Then run `conda install -c conda-forge lime` or `pip install lime`.
[github](https://github.com/marcotcr/lime)

Ensure you have dependencies like scikit-learn and numpy: `conda install scikit-learn numpy matplotlib`. Test the install by
opening Python and running `import lime; print(lime.__version__)`. This works seamlessly on Ubuntu since Miniconda manages
Python environments independently. [github](https://github.com/marcotcr/lime)

## Quick Usage Example

To explain a random forest prediction, use `LimeTabularExplainer` for tabular data:

```python
from lime.lime_tabular import LimeTabularExplainer
explainer = LimeTabularExplainer(train_data, feature_names=features, class_names=classes)
explanation = explainer.explain_instance(instance, model.predict_proba)
explanation.show_in_notebook()
```

This generates a visualization of feature contributions.
