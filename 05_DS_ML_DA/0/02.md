SciPy is a free, open-source Python library for scientific and technical computing, built on top of NumPy arrays.
[en.wikipedia](https://en.wikipedia.org/wiki/SciPy)

## Core Purpose

It extends NumPy's capabilities with high-level modules for optimization, linear algebra, integration, interpolation,
signal/image processing, statistics, FFT, ODE solvers, and special functions common in science and engineering.
[coursera](https://www.coursera.org/articles/what-is-scipy)

## Key Features

- **Subpackages**: `scipy.optimize`, `scipy.signal`, `scipy.stats`, `scipy.integrate`, `scipy.linalg`, and more for
  specialized tasks. [deepnote](https://deepnote.com/blog/scipy-in-python-the-ultimate-quickstart-guide)
- **NumPy Foundation**: Uses NumPy arrays for efficient numerical operations but adds comprehensive algorithms.
  [mode](https://mode.com/python-tutorial/libraries/scipy/)
- **Ecosystem Role**: Part of the SciPy Stack with Matplotlib, Pandas, and scikit-learn for complete scientific workflows.
  [w3schools](https://www.w3schools.com/python/scipy/scipy_intro.php)

## Common Uses

SciPy powers research in physics, engineering, data analysis, and finance—handling everything from signal filtering (as in
previous examples) to statistical testing and differential equations.
[geeksforgeeks](https://www.geeksforgeeks.org/machine-learning/introduction-to-scipy/)
