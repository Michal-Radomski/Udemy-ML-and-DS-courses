**AutoARIMA** (Automatic Auto-Regressive Integrated Moving Average) is an automated algorithm used in time series forecasting
to find the best-fitting ARIMA model for a given dataset without requiring manual trial and error.

---

### Understanding the Core Components

To understand AutoARIMA, it helps to break down standard **ARIMA$(p, d, q)$**:

- **AR ($p$ - Auto-Regressive):** Uses the relationship between an observation and a specified number of lagged (past)
  observations.
- **I ($d$ - Integrated):** Involves differencing the data (subtracting current values from past values) one or more times to
  make the time series stationary (meaning its mean and variance remain constant over time).
- **MA ($-$ Moving Average):** Uses the dependency between an observation and a residual error from a moving average model
  applied to lagged observations.

### What the "Auto" Part Does

Traditionally, data scientists determine the orders $p$, $d$, and $q$ manually by inspecting **Autocorrelation (ACF)** and
**Partial Autocorrelation (PACF)** plots—a tedious and subjective process.

**AutoARIMA** automates this entire workflow by:

1. **Determining the Differencing Order ($d$):** It tests unit root tests (like the Kwiatkowski-Phillips-Schmidt-Shin or
   Augmented Dickey-Fuller test) to find the optimal level of differencing needed to achieve stationarity.
2. **Searching the Parameter Space:** It iterates through combinations of $p$ and $q$ (often using a stepwise search
   algorithm, such as the Hyndman-Kandakar algorithm) to explore different model configurations efficiently.
3. **Optimizing via Information Criteria:** It evaluates each model using statistical metrics like **AIC** (Akaike
   Information Criterion) or **BIC** (Bayesian Information Criterion). The model with the lowest AIC/BIC score is selected as
   the optimal forecasting model.

### Key Benefits

- **Efficiency:** Saves significant time by automating model selection.
- **Objectivity:** Relies on mathematical optimization criteria rather than subjective visual interpretation of plots.
- **Flexibility:** Can handle seasonal variations if extended to **SARIMA** (Seasonal ARIMA).
