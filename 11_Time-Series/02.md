## 1\. Difference Between Prediction and Forecasting

Both **prediction** and **forecasting** are used in machine learning and data analysis to estimate unknown values. However,
they have slightly different meanings.

### Prediction

Prediction means estimating an unknown or future outcome using available data.

It does not necessarily involve time.

**Example:**

- Predicting whether a customer will buy a product.
- Predicting whether a student will pass an exam.
- Predicting the price of a house based on its size and location.

### Forecasting

Forecasting means estimating future values based on historical data, especially data collected over time (time series).

**Example:**

- Forecasting next month's sales.
- Forecasting tomorrow's temperature.
- Forecasting next year's company revenue.

### 2\. Difference Between Prediction and Forecasting

| Prediction                                              | Forecasting                            |
| ------------------------------------------------------- | -------------------------------------- |
| Estimates an unknown outcome.                           | Estimates future values.               |
| Does not require time-based data.                       | Usually uses time series data.         |
| Can be about past, present, or future unknown outcomes. | Focuses on future outcomes.            |
| Uses classification or regression, among other methods. | Often uses time series models.         |
| Example: Predict house prices.                          | Example: Forecast monthly house sales. |

**Remember:** Forecasting is a type of prediction, but not every prediction is forecasting.

---

## 3\. Python Example: Prediction

Let's predict house prices based on house size.

We will use Linear Regression.

python

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# House sizes (square feet)
X = np.array([[1000], [1500], [2000], [2500], [3000]])

# House prices (Euros)
y = np.array([100000, 150000, 200000, 250000, 300000])

# Create model
model = LinearRegression()

# Train model
model.fit(X, y)

# Predict price for a 2200 sq ft house
prediction = model.predict([[2200]])

print("Predicted House Price:", prediction[0])
```

**Output:**

text

```text
Predicted House Price: 220000.0
```

Here:

- Input: House size (2200 sq ft).
- Output: Predicted house price (€220,000).
- This is a prediction because we estimate a value based on house characteristics, not a time series.

---

## 4\. Python Example: Forecasting

Now let's forecast future sales using historical monthly sales data.

We will use a simple Linear Regression model.

python

```python
import numpy as np
from sklearn.linear_model import LinearRegression

# Historical monthly sales
months = np.array([
    [1], [2], [3], [4], [5], [6]
])

sales = np.array([
    1000, 1200, 1400, 1600, 1800, 2000
])

# Create model
model = LinearRegression()

# Train model
model.fit(months, sales)

# Forecast sales for month 7
future_month = np.array([[7]])

forecast = model.predict(future_month)

print("Forecasted Sales:", forecast[0])
```

**Output:**

text

```text
Forecasted Sales: 2200.0
```

Here:

- Input: Historical monthly sales.
- Output: Forecasted sales for month 7 (€2,200).
- This is forecasting because we use historical time-based data to estimate a future value.

## 5\. When Should You Use Each?

| Situation                    | Method      |
| ---------------------------- | ----------- |
| Predict customer purchases   | Prediction  |
| Predict house prices         | Prediction  |
| Predict student exam results | Prediction  |
| Forecast next month's sales  | Forecasting |
| Forecast stock prices        | Forecasting |
| Forecast future temperatures | Forecasting |

### Final Summary

Think about it this way:

- **Prediction:** What will happen or what is the unknown value?
- **Forecasting:** What will happen in the future based on historical time-based data?

Both are important in Data Science and Machine Learning.
