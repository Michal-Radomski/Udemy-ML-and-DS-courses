**Data normalization** is the process of scaling numeric data so that all values fit within a specific range (usually between
0 and 1) or follow a standard distribution.

When you have a dataset where different columns use vastly different units or scales (for example, tracking someone's age
from 0 to 100 alongside their income from $20,000 to $200,000), normalization prevents the larger numbers from overwhelming
machine learning models or statistical calculations.

---

### Common Methods of Normalization

#### 1. Min-Max Scaling (Range Scaling)

This method shifts and scales the data so that all values fall strictly between **0 and 1**.

- **The Formula:**

$$\text{Normalized Value} = \frac{\text{Value} - \text{Minimum}}{\text{Maximum} - \text{Minimum}}$$

- **Best used when:** You need your data bounded within a fixed range (like pixel values in images, which go from 0 to 255).

#### 2. Z-Score Standardization (Standard Scaling)

Instead of a fixed range, this centers the data around a **mean of 0** with a **standard deviation of 1**.

- **The Formula:**

$$\text{Normalized Value} = \frac{\text{Value} - \text{Mean}}{\text{Standard Deviation}}$$

- **Best used when:** Your data has outliers or you are using machine learning algorithms like linear regression or neural
  networks that perform better with normally distributed data.

---

### A Quick Example (Min-Max Scaling)

Imagine you have a list of house sizes in square feet: `[1000, 1500, 2000]`.

- **Minimum value:** 1000
- **Maximum value:** 2000

Applying Min-Max scaling:

- For `1000`: $\frac{1000 - 1000}{2000 - 1000} = \frac{0}{1000} = \mathbf{0.0}$
- For `1500`: $\frac{1500 - 1000}{2000 - 1000} = \frac{500}{1000} = \mathbf{0.5}$
- For `2000`: $\frac{2000 - 1000}{2000 - 1000} = \frac{1000}{1000} = \mathbf{1.0}$

The new normalized dataset becomes: `[0.0, 0.5, 1.0]`.
