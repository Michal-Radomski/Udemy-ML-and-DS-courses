Deep Neural Networks (DNNs), Convolutional Neural Networks (CNNs), and Recurrent Neural Networks (RNNs) are all deep learning
architectures but excel at different data types.

## Deep Neural Network (DNN)

Fully connected networks with layers of neurons where every neuron connects to every neuron in the next layer. Like the first
MNIST example we built.

**Key traits:**

- Input → Hidden layers (Dense) → Output
- Every input pixel connects to every neuron
- Learns any tabular/structured data

**Architecture**: `Input → Dense(512, relu) → Dense(512, relu) → Dense(10, softmax)`

**Best for**: Tabular data, embeddings, simple classification (97% MNIST accuracy)

## Convolutional Neural Network (CNN)

Specialized for **images/grid data**. Uses convolution filters to detect local patterns (edges, textures) instead of full
connections.

**Key traits:**

- **Conv2D layers**: Small filters (3×3) scan images, share weights across positions
- **Pooling**: Downsamples (MaxPool2D), reduces parameters
- **Spatial hierarchy**: Edges → Shapes → Objects

**Architecture**: `Input(28,28,1) → Conv2D → Pool → Conv2D → Pool → Flatten → Dense` (99.3% MNIST)

**Best for**: Images, videos (self-driving cars, medical scans)

## Recurrent Neural Network (RNN)

Designed for **sequences** where order matters. Has loops to maintain "memory" of previous inputs.

**Key traits:**

- **Recurrent connections**: Same weights reused across time steps
- **Hidden state**: Carries information from past to future
- **Time dependency**: Processes data step-by-step

**Architecture**: `Input(t) → LSTM/GRU → Hidden state → Output(t)`

**Best for**: Text, time series, speech (language models, stock prediction)

## Key Differences Table

| Feature         | DNN            | CNN                  | RNN        |
| --------------- | -------------- | -------------------- | ---------- |
| **Data Type**   | Tabular        | Images               | Sequences  |
| **Connections** | All-to-all     | Local filters        | Time loops |
| **Parameters**  | Millions       | Thousands            | Reused     |
| **Memory**      | None           | None                 | Sequential |
| **MNIST Acc**   | 97.8%          | **99.3%**            | ~98%       |
| **Use Case**    | Credit scoring | **Object detection** | ChatGPT    |

## Architecture Visual Comparison

```
DNN:      Input → [Dense] → [Dense] → Output
                    ↑  ↑
                 All-to-all connections

CNN:     Input → [Conv→Pool] → [Conv→Pool] → Flatten → Dense
              ↑    Filters slide across image

RNN:   Input1 → [RNN] ─→ Output1
         ↘        ↗
       Input2 ───┘ Hidden state
```

**From our MNIST examples**: DNN (97.8%) → CNN (99.3%). CNN wins because convolution captures **spatial patterns** that
digits have, while DNN treats pixels independently.
