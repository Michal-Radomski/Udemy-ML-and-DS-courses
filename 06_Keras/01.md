Keras is an open-source, high-level neural networks API written in Python, designed for fast experimentation with deep
learning models. It's now the official high-level API of TensorFlow and supports multiple backends like JAX and PyTorch.
[geeksforgeeks](https://www.geeksforgeeks.org/deep-learning/what-is-keras/)

## Core Purpose

Keras simplifies building, training, and deploying neural networks by providing user-friendly interfaces over complex
frameworks, focusing on simplicity, modularity, and extensibility for tasks like image classification and NLP.
[dev](https://dev.to/dazevedo/keras-understanding-the-basics-with-a-detailed-example-4b0h)

## Key Features

- **High-level API**: Define models with Sequential or Functional APIs, then compile, fit, evaluate, and predict easily.
- **Multi-backend**: Works with TensorFlow, JAX, or PyTorch via Keras 3.
- **Built-in support**: Layers like Dense, Conv2D, LSTM; optimizers, losses, and metrics.
  [simplilearn](https://www.simplilearn.com/tutorials/deep-learning-tutorial/what-is-keras)

## Common Workflow

```
from tensorflow import keras
model = keras.Sequential([keras.layers.Dense(64, activation='relu'), keras.layers.Dense(10)])
model.compile(optimizer='adam', loss='mse')
model.fit(x_train, y_train, epochs=10)
```

Used widely for CNNs, RNNs, and production ML since its integration into TensorFlow.
[tensorflow](https://www.tensorflow.org/guide/keras)
