A CNN + RNN model combines Convolutional Neural Networks (CNNs) for spatial feature extraction with Recurrent Neural Networks
(RNNs) for sequential processing, commonly used in video analysis, text-image tasks, or time-series with images.
[collab.dvb](https://collab.dvb.bayern/spaces/TUMlfdv/pages/69119924/Recurrent+Neural+Networks+-+Combination+of+RNN+and+CNN)

## Core Concept

CNNs excel at detecting local patterns (edges, textures) in 2D data like images or video frames, producing compact feature
maps. RNNs (or LSTMs/GRUs) then process these features sequentially across time steps or sequence positions, capturing
temporal dependencies. [ncbi.nlm.nih](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC5600938/)

## Common Architectures

- **CRNN (CNN-RNN)**: CNN backbone → RNN layers → classification. Popular for OCR (image to text) and video classification.
- **RCNN (Recurrent CNN)**: Recurrent connections within convolutional layers for iterative refinement on static images.
  [collab.dvb](https://collab.dvb.bayern/spaces/TUMlfdv/pages/69119924/Recurrent+Neural+Networks+-+Combination+of+RNN+and+CNN)

| Architecture          | Flow                                  | Typical Use Case                                                                                                                                      |
| --------------------- | ------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| CNN → RNN             | Frames → features → sequence modeling | Video action recognition [collab.dvb](https://collab.dvb.bayern/spaces/TUMlfdv/pages/69119924/Recurrent+Neural+Networks+-+Combination+of+RNN+and+CNN) |
| Recurrent Conv Layers | Spatial + temporal recurrence         | Object recognition with context [ncbi.nlm.nih](https://www.ncbi.nlm.nih.gov/pmc/articles/PMC5600938/)                                                 |

## Keras Example: Video Frame Classification

This predicts action labels from a sequence of 10 frames (shape: samples, 10, 64, 64, 1).

```python
# =============================================================================
# CNN + RNN: Video Action Classification
# Input: (samples, timesteps=10, height=64, width=64, channels=1)
# =============================================================================
from tensorflow.keras.models import Sequential
from tensorflow.keras.layers import Conv2D, MaxPooling2D, Flatten, TimeDistributed, LSTM, Dense
import numpy as np

# Cell 1: Generate dummy video data
timesteps, h, w, c = 10, 64, 64, 1
samples = 1000
X = np.random.random((samples, timesteps, h, w, c))
y = np.random.randint(0, 5, samples)  # 5 action classes

split = int(0.8 * samples)
X_train, X_test = X[:split], X[split:]
y_train, y_test = y[:split], y[split:]

# Cell 2: CNN+RNN Model
model = Sequential([
    # CNN feature extractor per frame (TimeDistributed applies CNN to each timestep)
    TimeDistributed(Conv2D(32, (3,3), activation='relu'), input_shape=(timesteps, h, w, c)),
    TimeDistributed(MaxPooling2D((2,2))),
    TimeDistributed(Conv2D(64, (3,3), activation='relu')),
    TimeDistributed(MaxPooling2D((2,2))),
    TimeDistributed(Flatten()),  # Features per frame: ~1600 dims

    # RNN processes temporal sequence of frame features
    LSTM(128, return_sequences=False),  # Final hidden state
    Dense(5, activation='softmax')  # 5 classes
])

model.compile(optimizer='adam', loss='sparse_categorical_crossentropy', metrics=['accuracy'])
model.summary()

# Cell 3: Train
history = model.fit(X_train, y_train, epochs=10, batch_size=32, validation_split=0.2)

# Cell 4: Evaluate
loss, acc = model.evaluate(X_test, y_test)
print(f"Test accuracy: {acc:.3f}")
```

## Key Benefits

- **CNN**: Reduces spatial dimensions efficiently (e.g., 64x64 → 128 features per frame).
  [collab.dvb](https://collab.dvb.bayern/spaces/TUMlfdv/pages/69119924/Recurrent+Neural+Networks+-+Combination+of+RNN+and+CNN)
- **RNN/LSTM**: Models dependencies like "hand moving toward ball → kick action".
- Replace LSTM with GRU for speed; add Dropout(0.5) to prevent overfitting.
